📄 IntelliDoc AI – Smart Document Assistant

🔗 Live Demo: https://intellidoc-ai.streamlit.app/

---

🚀 Overview

IntelliDoc AI is a Generative AI-powered document assistant that enables users to upload documents and interact with them intelligently. It leverages Large Language Models (LLMs) to analyze, summarize, and answer questions from document content in real time.

This project demonstrates practical implementation of AI concepts like document parsing, prompt engineering, and interactive querying.

---

✨ Key Features

- 📂 Upload PDF/Text documents
- 🤖 AI-powered document understanding
- 💬 Ask questions based on document content
- 🧠 Context-aware responses using LLMs
- ⚡ Fast and simple Streamlit interface
- 🌐 Deployed and accessible online

---

🛠️ Tech Stack

- Frontend & UI: Streamlit
- Backend: Python
- AI/LLM: OpenAI / Google Gemini (API-based)
- Libraries:
  - PyPDF / PDF processing
  - LangChain (optional integration)
  - Pandas, NumPy

⚙️ Installation & Setup

1. Clone the Repository

git clone https://github.com/your-username/intellidoc-ai.git
cd intellidoc-ai

2. Create Virtual Environment

python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate

3. Install Requirements

pip install -r requirements.txt

4. Add API Keys

Create a ".env" file and add:

OPENAI_API_KEY=your_api_key
# OR
GEMINI_API_KEY=your_api_key

5. Run the App

streamlit run app.py
